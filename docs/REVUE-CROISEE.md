## Procédure

1. Donner à l'autre équipe les sources, le README et les fiches UC, ou l'accès au dépôt après publication.
2. Lui faire lancer `mvnw.cmd clean verify` et démarrer l'application.
3. Lui faire suivre DEMONSTRATION.md et examiner la cohérence diagrammes/code.
4. Recueillir ses remarques réelles ci-dessous ; créer un ticket par correction nécessaire.
5. Corriger, relancer les tests et faire confirmer les corrections bloquantes.
